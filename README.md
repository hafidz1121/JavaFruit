# Java Fruit Company Profile Website (Next.js)

This is a company profile website for **CV Intiplant Agro Lestari** (Java Fruit), built using **Next.js 14 (App Router)**. The site highlights premium Cavendish and Mas Kirana bananas, sustainable farming practices, and modern post-harvest technology.

## 📁 Project Structure

- `/app`: Contains layout, page, and API routes (sitemap, robots).
- `/components`: Reusable UI components (Header, Footer, Hero, etc.).
- `/public/assets`: Images and static assets.

## 🚀 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: JavaScript (React 18)
- **Styling**: Global CSS with custom properties (no CSS-in-JS or Tailwind)
- **Fonts**: `next/font` (Fraunces, Inter, IBM Plex Mono)
- **Images**: `next/image` with AVIF/WebP optimization

## 🛠️ Setup & Development

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build

# Start the production server
npm start
```

## 🌐 Key Features

- **SEO Optimized**: Uses Next.js `metadata` API, structured data (JSON-LD), and a dynamic sitemap.
- **Responsive Design**: Adapts to mobile, tablet, and desktop screens.
- **Performance**: Images are optimized, and fonts use `display: swap`.
- **Security**: No active forms or user-generated content, reducing attack surfaces.
